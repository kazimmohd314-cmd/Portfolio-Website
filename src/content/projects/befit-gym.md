## Overview

BE FIT GYM is a multi-page web platform created for a regional fitness brand. It presents training programs, facility photography, and membership plans.

The site is engineered for fast load speeds on mobile networks. It features an interactive body mass index calculator for prospective members.

## Key Features

- Client-side BMI calculator computing instant health range diagnostics.
- Clear tier comparisons highlighting training inclusions and personal coaching.
- Mobile-optimized media galleries displaying gym facilities and equipment.
- Direct lead generation flows linking prospective gym members to management.

## Technical Execution

The project emphasizes semantic markup and lightweight CSS architecture. Scripts are kept modular to ensure instant interaction on handheld devices.
